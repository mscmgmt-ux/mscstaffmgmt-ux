# スクリプトプロパティ 一覧

対象: GAS プロジェクト `MSC-EventOps` の「プロジェクトの設定」→「スクリプト プロパティ」

**このファイルに値そのものを書かない。** キーの名前と意味だけを定める。
実際の値は GAS の画面で直接入力する（`docs/secrets-placement.md` 参照）。

## 命名規則

- **大文字スネークケース。** GAS のプロパティは名前空間を持たないため、**接頭辞でグループ分けする**
- 接頭辞は `APP_` / `AUTH_` / `ADMIN_` / `SHEET_` / `MAIL_` / `DRIVE_` の6つ
- 時間の単位を名前の末尾に入れる（`_SEC` / `_MS` / `_DAYS`）。単位の取り違えを防ぐため
- 個数・上限は `_LIMIT`、識別子は `_ID`

## A. 今すぐ登録するもの（Phase 0）

| キー | 型 | 意味 | 備考 |
|---|---|---|---|
| `APP_ENV` | 文字列 | 使用するスプレッドシートの切り替え | `prod` または `dev`。**開発中は `dev`** |
| `AUTH_ACCESS_CODE` | 文字列 | スタッフ用の共通4桁コード | 年度共通。漏れたときだけ変更 |
| `AUTH_TOKEN_SECRET` | 文字列 | 端末の再入力免除トークンの署名に使う秘密鍵 | **ランダムな32文字以上を生成して入れる。** 推測可能な文字列にしない |
| `ADMIN_EMAILS` | カンマ区切り | 管理者として許可するメールアドレス | 空白なしで区切る |
| `SHEET_ID_PROD` | 文字列 | 本番スプレッドシートの ID | URL の `/d/` と `/edit` の間 |
| `SHEET_ID_DEV` | 文字列 | 開発スプレッドシートの ID | 同上 |

**6件です。** Phase 0 の疎通確認だけなら `APP_ENV` と `SHEET_ID_DEV` があれば動きますが、
後で入れ忘れると原因が分かりにくいので、まとめて登録しておくことを勧めます。

## B. Phase 1（認証・回答受付）で追加するもの

4桁コードの総当たり対策。**個人単位のロックアウトは作らない**方針
（GAS は呼び出し元 IP を取得できないため。`CLAUDE.md` §3 の決定）。

| キー | 型 | 意味 | 目安 |
|---|---|---|---|
| `AUTH_FAIL_DELAY_MS` | 数値 | コード誤りのときに意図的に待つミリ秒 | `1500` |
| `AUTH_FAIL_LIMIT` | 数値 | この回数を超えたら全体を一時停止する | `30` |
| `AUTH_FAIL_WINDOW_SEC` | 数値 | 失敗を数える時間の幅（秒） | `600`（10分） |
| `AUTH_LOCK_SEC` | 数値 | 閾値を超えたときに停止する秒数 | `900`（15分） |
| `AUTH_SESSION_DAYS` | 数値 | 一度通過した端末が再入力を免除される日数 | `30` |

`AUTH_SESSION_DAYS` は仕様書の「一度通過した端末は一定期間再入力不要」に対応する。

## C. Phase 3（督促メール）で追加するもの

| キー | 型 | 意味 | 目安 |
|---|---|---|---|
| `MAIL_FROM_NAME` | 文字列 | 送信者の表示名 | `MSC イベント運営事務局` |
| `MAIL_DAILY_LIMIT` | 数値 | 1日に送る宛先数の上限 | `90`（**実際の上限は無料 Gmail で100。余裕を持たせる**） |
| `MAIL_BATCH_SIZE` | 数値 | トリガー1回で送る件数 | `20` |
| `MAIL_NOTIFY_TO` | 文字列 | 送信失敗など異常時に事務局へ知らせる宛先 | |

`MAIL_DAILY_LIMIT` を100ちょうどにしないこと。回答確認メールや再送が同じ枠を食うため、
上限に張り付くと督促が途中で止まる。**Workspace に移行したら 1,500 まで上げられる。**

## 使うときの約束

- **プロパティ名をコードに直接書かない。** 定数として1か所にまとめ、そこから参照する。
  綴り違いは実行時まで気づけないため
- **`getProperty` の戻り値が `null` のときにそのまま進めない。** 未登録は明確なエラーにする。
  開発者不在で運用するため、「なぜか動かない」を残さない
- 数値のプロパティは文字列で返る。**必ず数値に変換してから使う**
- `APP_ENV` が `prod` 以外のときは、**本番スプレッドシートを絶対に開かない**実装にする

## 注意

- スクリプトプロパティは、**GAS プロジェクトの編集権限を持つ人なら誰でも読めます。**
  したがって編集権限は事務局の最小限の人数に留めてください
- プロパティは GAS プロジェクト単位です。**本番用と開発用でプロジェクトは分けず、
  `APP_ENV` で参照先シートを切り替えます**（デプロイの管理が増えるのを避けるため）
