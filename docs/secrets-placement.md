# 秘密情報の置き場所 対応表

**このファイルに値そのものを書かない。** 「何を、どこに置くか」だけを定める表である。

このリポジトリは GitHub の **public** リポジトリであり、コミットしたものは全世界から読める。
新しく秘密情報を扱うときは、**ファイルを作る前に** この表に行を足し、`.gitignore` に追記する。

## 置き場所の種類

| 記号 | 場所 | 誰が読めるか |
|---|---|---|
| **P** | GAS の Script Properties（PropertiesService） | GAS のコードと、GAS プロジェクトの編集権限を持つ人 |
| **S** | 非公開 Google スプレッドシート | 共有された事務局メンバー |
| **D** | Google Drive の非公開フォルダ | 共有された事務局メンバー |
| **L** | ローカルのみ（`.gitignore` 済み・コミットしない） | 開発機の所有者 |
| **G** | GitHub（public・誰でも読める） | 全世界 |

## 対応表

| 情報 | 置き場所 | 理由・補足 |
|---|---|---|
| スタッフ認証の4桁コード | **P** | フロント JS とスプレッドシートの両方に置かない。判定は GAS 側で行う |
| 4桁コードの失敗カウンタ | **P**（CacheService） | 最大6時間で消える。消えるとロックが解除される側に倒れる（NOTES.md 参照） |
| 管理者の許可メールアドレス一覧 | **P** | スプレッドシートに置くと事務局メンバーが自分で追記できてしまう |
| スタッフの氏名・カナ・所属・カテゴリ | **S**（「スタッフ」タブ） | 個人情報。GitHub に出さない |
| スタッフのメールアドレス | **S**（「スタッフ」タブ） | 同上。督促メールの宛先として GAS が読む |
| スタッフの回答内容 | **S**（「回答」タブ） | — |
| 事務局の参加者決定 | **S**（「事務局決定」タブ） | — |
| スプレッドシートの ID | **P** | GAS から参照する。フロントには渡さない |
| GAS Web App の URL（スタッフ用） | **G** | **隠せない。** フロント JS に書く以上、公開サイトから誰でも読める |
| GAS Web App の URL（管理者用） | **G** | 同上。URL の秘匿を防御に数えない。許可メール照合が防御 |
| GAS のスクリプト ID / デプロイ ID | **L**（`.clasp.json`） | 秘密ではないが環境依存。本番/開発の取り違えを防ぐため除外する |
| clasp の OAuth トークン | **L**（`.clasprc.json`） | **最も危険。** 漏れると GAS・スプレッドシート・Gmail を第三者が操作できる |
| 本番/開発の切り替え設定 | **L**（`config.local.js`） | 開発機ごとに異なる。`.gitignore` 済み |
| ホテル提出ファイル（名簿） | **D** | 宿泊者の氏名を含む。版管理は Drive のフォルダで行う |
| バックアップ CSV | **D** | 回答・氏名・メールを含む |
| Google アカウントのパスワード・2段階認証のバックアップコード | **どこにも置かない** | パスワードマネージャ等、このシステムの外で管理する |

## 重要な前提（防御を数え間違えないために）

- **GAS Web App の URL は秘密にできない。** GitHub Pages は公開サイトであり、フロントの
  JavaScript に書いた URL は誰でも読める。リポジトリを private にしても、公開サイトを
  見れば同じことである（サイト自体を非公開にできるのは GitHub Enterprise Cloud のみ）
- したがってスタッフ用 API の防御は、実質的に **4桁コード + 氏名/メールの一致** の2段だけである
- 管理者用 API の防御は、**Google ログイン + 許可メールリストの照合** である。
  照合を実装するまで、URL を知っている全 Google ユーザーが呼べる
- **カスタム HTTP ヘッダは使えない**（CORS プリフライトを避けるため）。
  認証値は `Authorization` ヘッダではなくリクエストボディに入れる
