# design-explore — デザイン検討用のコピー環境

**ここは本番のフロントではありません。** デザイン案を実際に動く形で見比べるための隔離環境です。

## なぜ分けてあるか

案を試して気に入らなければ、**このディレクトリごと捨てれば元に戻ります。**
`index.html` などの本番フロントはリポジトリのルートに置く方針（`CLAUDE.md` §1）なので、
ここを消してもプロジェクト本体には一切影響しません。

現時点で本番フロントのファイルは1つも作っていないため、**この環境は完全に独立しています。**

## 中身

| ディレクトリ | 内容 |
|---|---|
| `design-1/` | 指示書 `docs/指示書_イベント運営サイト.md` をそのまま実装した案（ダーク × 紫グラデーション） |

案を増やすときは `design-2/` `design-3/` と横に並べます。既存の案は書き換えません。

## 見かた

`design-1/index.html` をブラウザで開いてください（ダブルクリックで開けます）。
サーバーは不要です。画面上部のタブで3画面を行き来できます。

## 各案に共通する約束

- **API を呼びません。** GAS にもスプレッドシートにも接続しません
- **表示されている氏名・メール・イベント名・ホテル名・数値はすべて架空のダミーです。**
  実在のスタッフ情報は一切含みません（`CLAUDE.md` §2-1）
- 検討用なので、本番に採用が決まった時点でルート直下へ作り直します。
  このディレクトリのファイルをそのまま本番に移動しません

## 採用が決まったら

1. 採用案の番号を `CLAUDE.md` §3（設計上の確定事項）に理由とともに記録する
2. トークン（`css/tokens.css`）を本番の `css/` へ移す
3. `docs/ux-criteria.md` を作り、この指示書の項目を採点軸に落とす
4. `design-explore/` は削除してよい（履歴は git に残る）
